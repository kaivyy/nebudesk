# NEBUDESK PROJECT AUDIT

## 1. Current Stack
- **Frontend**: React 19, Vite 8, TypeScript, Tailwind CSS v4, Zustand, xterm.js
- **Backend**: Node.js, Fastify, fastify-websocket, node-pty, systeminformation, dockerode
- **Database**: None yet (SQLite + Prisma planned)
- **Authentication**: None yet
- **WebSocket**: Active for Terminal (fastify-websocket)
- **Filesystem**: Read-only directory listing implemented (restricted to `/root/nebudesk`)
- **Terminal**: Basic xterm.js + node-pty implemented, no tmux/scrollback persistence yet.
- **Docker**: Read-only container listing implemented.
- **System Monitoring**: CPU, RAM, Storage, Processes implemented.
- **Services**: systemctl status and journalctl tail implemented.

## 2. Status

**Implemented (P0/P1):**
- Desktop Shell (Menu Bar, Dock, Window Manager with drag/resize/minimize/maximize).
- Files app UI and basic read functionality.
- Terminal UI and basic interactive shell.
- System Monitor dashboard.
- Docker container listing.
- Services listing and logs viewer.

**Missing / Partially Implemented (P1/P2):**
- **Security & Auth:** Missing user login, session cookies, origin validation.
- **Database Persistence:** Desktop state (windows, layout) is currently in client-side Zustand only. Needs SQLite.
- **Files App:** Missing create, edit, rename, delete, upload, download features.
- **Terminal Persistence:** No reconnect capability using `tmux` or bounded scrollback.
- **Docker & Services Actions:** Missing start/stop/restart buttons for containers and services.
- **Settings App:** Appearance (light/dark/wallpaper) not implemented.
- **Testing:** No frontend or backend automated tests.

**Risky / Technical Debt:**
- Terminal backend spawns unrestricted bash without authentication.
- API endpoints lack authorization checks.
- Filesystem API uses naive regex replacement for path traversal protection, needs `path.resolve` strictly validated against root.

## 3. Priority Plan for Next Execution

**Priority P0 (Security & Persistence):**
1. Setup Prisma and SQLite.
2. Implement Authentication (Login UI, Sessions, Secure HTTP-only cookies).
3. Secure all API and WebSocket routes.

**Priority P1 (Core Features Expansion):**

7. Docker & Services: Add start/stop mutations.

**Priority P2 (Polish & Testing):**
